# UI: 3D-карусель карточек + модалка

Лёгкий CSS-элемент (без Three.js / WebGL). Карточки — обычный DOM. Можно вставлять в любой сайт: принтеры, услуги, товары, портфолио.

Референс в этом проекте: `views/partials/featured-printers.ejs`, стили в `views/partials/head.ejs`, данные — таблица `featured_printers`.

---

## Карусель

- 6–10 карточек (здесь до 9). Видны центр и соседи слева/справа, остальные уходят в перспективу (`perspective` + `rotateY` + `translateZ`).
- Центр крупнее, по бокам меньше и под углом. Лента зациклена.
- Карточка: фото (или схема), бренд/категория, название, короткие мета-теги.
- Без бесконечного 60fps-цикла: смена индекса + CSS `transition`. Автопрокрутка раз в ~4.5 с, пауза при наведении, вне экрана и при открытой модалке. `prefers-reduced-motion` — обычная горизонтальная лента, без 3D.

**Листание карусели**

- кнопки влево/вправо;
- колесо мыши и горизонтальный жест трекпада (курсор над каруселью; одно деление = одна карточка);
- стрелки клавиатуры, когда фокус на ленте;
- клик по боковой карточке — она становится центральной.

**Клик по карточке** (центр или сосед слева/справа): эта карточка выходит в центр **и** открывается её модалка. Свайп по ленте модалку не открывает.

## Модалка

Поверх страницы, z-index выше всего. Фон затемнён + лёгкий blur. Клик по затемнению, крестик или Escape — закрыть.

**Размер**

- Ширина ~720px (не 50% экрана).
- Высота **80vh** на десктопе (на Full HD ≈ 860–900px).
- Телефон: почти вся ширина и высота (~96vw / 96dvh).

**Содержимое сверху вниз**

1. Крупное фото. Исходник квадрат **600×600**. Не обрезать: `object-fit: contain`, белый фон, картинка целиком вписывается в отведённую область.
2. Название.
3. Текстовое **описание** — преимущества / суть объекта (поле из БД).
4. **Таблица характеристик** из БД, со своей полосой прокрутки. Пустые поля не показывать.

Пока модалка открыта, карусель на фоне не крутится сама. При перелистывании внутри модалки **геометрия окна не прыгает**: фото, строка бренда, название и описание занимают фиксированную высоту; меняется только содержимое. Длинный текст описания и таблица характеристик скроллятся внутри своих блоков.

**Листание внутри модалки** (не закрывая её)

- крупные графические стрелки слева и справа от окна;
- клавиши **←** и **→**;
- тот же эффект: предыдущая / следующая карточка, контент модалки обновляется, карусель синхронно ставит её в центр.

На одну карточку стрелки не нужны.

## Данные и картинки

- Состав витрины правится в админке (порядок, скрыть, заменить, описание, характеристики).
- Фото для git: `assets/…` с именем из бренда+модели (дефисы/подчёркивания не важны). Загрузка через форму — только на этот сервер, не в git.
- Свои снимки, не автоскачивание с сайтов производителей.
