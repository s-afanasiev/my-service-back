# Шорт-лист: каталог популярных моделей (этап 2)

Рабочий документ. Источник данных — три среза (см. §1). Цель: наполнить каталог `printers`
актуальными моделями (~70 позиций, ядро ≈50). Для каждой модели при заполнении:
спеки проверить по официальным данным, описание писать уникальным текстом,
`is_featured = false` (в карусель вручную через админку).

## 1. Методология

1. **Ассортимент живого магазина** — salon2116.ru, выборка «принтеры», все 109 позиций
   по брендам HP, Canon, Pantum, Kyocera, Катюша, Brother, Xerox, Epson.
   Показывает, что реально покупается сейчас.
2. **Спрос по поисковым запросам** — рейтинг CopyGroup по статистике запросов за 2024 год
   (топ-20: M428dw, MF446x, Phaser 3020, Neverstop 1000w, P1102, B225, M6500…).
   Показывает установенную базу и интерес владельцев (потенциальных клиентов заправки).
3. **Хиты маркетплейсов** — обзор ZOOM.CNews (Deli M1820W, Pantum BM5220ADW, Epson L3251,
   Cactus CS-LP1120B, Fplus PB301DNW). Новые растущие бренды.

Легенда: ⭐ — ядро (в первую очередь); «уст.» — важна из-за большой установленной базы,
хотя уже не продаётся ( Samsung, старые HP/Canon — основной поток заправки ).
«Картридж» — предварительная оценка, помечено «уточнить» там, где нужна проверка.

## 12. Порядок заполнения

1. Согласовать список (пометки ⭐ — первые ~50).
2. Для каждой модели: проверить спеки (формат, скорость, dpi, duplex/wifi, год,
   картридж) — данные вносить только проверенные, спорное поле оставлять пустым.
3. Уникальное описание 2–4 абзаца на модель (по шаблону существующих: что за модель,
   чем хороша, нюанс заправки/ремонта).
4. Залить seed-скриптом (`is_featured=false`), фото — SVG-заглушки, добавить
   по мере поступления. 9 моделей карусели выбираются в админке.
5. Админке добавить режим «каталог»: список всех моделей, добавление без флага,
   «убрать из карусели» отдельно от «удалить».
